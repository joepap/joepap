Roster import (ConnectPlus export — .xlsx or .csv)

Map columns

Pick which column feeds each field. Use either Full name, or Last + First. "Portal status" enables the green-lane / portal-card flags; "Date of birth" (optional) helps tell apart members with identical names during license scans.

Which member statuses are ELIGIBLE for a ballot (green)?

Only "Active" is pre-checked (actives vote on the contract). Unchecked statuses show RED at check-in.

Payroll dues list (the dues authority)

The DC payroll union-dues report as a CSV/xlsx with columns emplid, last, first, middle, ssn4, grade, step. Once loaded, being on this list is what makes a member GREEN (eligible). Members not on it go to the Discrepancy Table; people on it but not in NEP show up yellow (payroll-only).

Paper dues roll (optional second list)

Flags matching members with "on paper roll"; reports names it can't match.

Dept ID / pat tag list (optional)

A list mapping pat tag numbers to members (any spreadsheet with a tag number + name or member #). Enables instant lookup when a department ID barcode is scanned or its number is typed into search.

Check-in confirmation email

Each member gets a "you're checked in — vote before the meeting ends" email with the meeting-page link, sent in the background (a mail outage never slows the line). Every attempt is logged: see the counters and the Email log export.

Event-morning reset

Clears ALL check-ins, corrections, not-found entries, discrepancy queue and provisional members from rehearsal/testing — keeps the roster, payroll list, dues blocks and settings. Do this once before doors open, never after real check-ins begin.
